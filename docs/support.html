Camvital Scan Support

Camvital Scan is intended for general wellness and fitness awareness. It is not a medical device and should not be used for diagnosis or emergency care.

Need help?

  • Review the project repository: ai-powered-pulse-monitor
  • Report an issue or request help: GitHub Issues

Best results

  • Use a physical iPhone, not the simulator.
  • Cover the rear camera and flash gently.
  • Hold still for the full one-minute session.
  • Review optional Apple Health permissions in iPhone Settings if needed.
